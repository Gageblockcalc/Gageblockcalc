About GageBlockCalc

GageBlockCalc builds a gage block stack for a length you type in. It picks blocks from a real set, uses the fewest blocks that add up to that length, and shows the list largest first.

The sets are the common shop sets: inch 81-piece, 36-piece, and 28-piece, and metric 112-piece and 88-piece. Wear blocks can be included on the outside of a stack. A sine bar page turns an angle into a stack height and opens the same solver.

Who it is for

It is for machinists, toolmakers, inspectors, and students who need a stack at the bench. You do not need an account. You do not need to install a store app. Open the calculator, pick the set that matches the box in front of you, and type the target in that set's unit.

Free, with no login

The calculator stays free. There is no paywall on a stack and no login. Some pages link to Amazon. As an Amazon Associate I earn from qualifying purchases. Those links are optional. The calculator works the same if you never click one.

The terms are on the terms page. Privacy for this site and for Ask a Machinist is on the privacy page.

It runs in the browser

The stack math runs on your device. After you open the calculator, the browser keeps a copy of the app files, so a stack still builds when the network drops. You can also install the site from the browser's install prompt and open it like an app. A how-to page you have not opened yet is not in that first cache. Open it once on the network and the browser can keep that copy too.
