How to Check Calipers with Gage Blocks

A caliper check compares the caliper reading to a length you already know. The gage block is that length. This is a shop check. It is not a calibration with an uncertainty budget. If the job needs a calibration, send the caliper to a lab.

Steps

  1. Clean the jaws and the block. Wipe the jaw faces and the gage block. A chip on a jaw reads as part of the length.
  2. Check zero with the jaws closed. Close the jaws the way you will close them on a part. If zero is off, every later reading includes that error. Set zero only if the tool is meant to be zeroed, and then check a block anyway.
  3. Measure a known block in the flat of the jaws. Use the flat measuring faces, not the knife edge at the tip, unless you are checking a groove. Approach the size the same way each time and write the reading down.
  4. Repeat near the tip and deeper in the jaws. A reading that changes as you move the block along the jaws means the jaws are not parallel. That is the caliper, not the block.
  5. Check a second length. One size can hide a scale error. Check a short block and a longer one. Compare the difference to the accuracy the maker states for that caliper. The last digit on the display is the resolution, which is a smaller claim than the accuracy.

Worked example

On an 81-piece inch set these three lengths are each one block, so you are not stacking error on top of the caliper:

1.000 in1.000Open 1.000 in
4.000 in4.000Open 4.000 in

Close the jaws and note zero. Measure the 0.250 block near the tip of the jaws and again closer to the beam. Then do the same with the 1.000 block. If both spots and both sizes agree with the blocks, within the accuracy printed for that caliper, the tool is behaving at those two lengths. The 4.000 block is the check for a longer-range caliper. A 0 to 1 inch tool never sees that block.

Write the readings down. "It looked close" is not a check you can repeat next month. Wear blocks are optional here. A single block has no wring in the length you are using, which keeps the check simpler. If you do stack, wring first. The wringing steps are the difference between a stack and three loose blocks.

FAQ

Is a caliper as accurate as a gage block?

No. A gage block is the length standard in this check. The caliper is the tool being checked. A difference inside the caliper accuracy the maker printed is what that tool is specified to do. A difference larger than that, or a difference that changes along the jaws, is a reason to stop using it for that job.

Does a good zero mean the caliper is fine?

No. Zero only shows that the jaws meet. A worn jaw or a scale error shows up at a real length. Check at least two sizes.

Which blocks should I use?

On an 81-piece inch set, 0.250 in, 1.000 in, and 4.000 in are each a single block. Use sizes that fall inside the caliper range you actually use.
