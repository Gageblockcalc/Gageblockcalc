How to Verify a Height Gage with Gage Blocks

A height gage reads height above a surface plate. A gage block, or a wrung stack, is a known height you can set that reading against. Match the contact and the approach you will use on the part. A different contact, or a different direction, is a different measurement.

Steps

  1. Clean the plate, the base, and the block. The surface plate is the zero of a height measurement. Dirt under the gage base or under the block adds to the height.
  2. Use one known height, then a second. A single block is the cleanest setting master. A second height shows a column error that one setting hides.
  3. Put wear blocks on the outside when the stack is rubbed. If the stack sits on the plate and the contact rubs the top, wring a wear block on each end. The calculator target then includes those two blocks.
  4. Touch the stack the way you will touch the part. Use the same contact, from the same direction. Zero there, or record the reading. Then move to the part without changing the setup more than the measurement needs.
  5. Treat squareness as its own check. A height that matches a block at one spot does not prove the column is square to the plate. Check squareness separately if the part is tall.

Worked example

On an 81-piece set, 2.000 in with wear blocks off is the single 2.000 block. That is the simple setting master: one block, no wring, sitting on the plate.

Open 2.000 in, wear off

If the stack will be rubbed, include the wear blocks in the 2.000 in total. Wear on, the same target is 1.000 + 0.900 + 0.050 + 0.050. The two 0.050 blocks are the outside faces. Wring them on last, one on each end.

Open 2.000 in with wear blocks

Set the height gage on the plate. Bring the contact down onto the 2.000 block and zero, or write the reading. Then check a second height you can build, such as the 4.000 in block (open 4.000 in), if the column reaches it. A gage that matches 2.000 and misses 4.000 has a column error the first block did not show.

Let the gage, the plate, and the blocks sit together before a tight check. A block just out of a warm hand is long. The reference temperature is 20 °C (68 °F). The temperature page computes the change.

FAQ

What does wear=1 do to a 2 inch target?

The target is the finished stack, and the two 0.050 inch wear blocks are part of that 2.000 inch total. On the 81-piece set the solver builds 1.000 + 0.900 + 0.050 + 0.050. Wear off, the same 2.000 inch target is the single 2.000 block.

Can I set a height gage on one block and trust the whole column?

One block proves the reading at that height. Check a second height inside the range you use. Squareness of the column to the plate is a separate check.

Does the block need to be the same grade as the part tolerance?

The block has to be tighter than the decision you are making. An AS-2 working block is a poor master for a tolerance that is only a few ten-thousandths. The certificate, not the nominal size alone, is the length you set to when the tolerance is tight.
