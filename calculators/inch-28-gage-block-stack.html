Formula

Target = b₁ + b₂ + … + bₙ (minimise n)
28-pc thin series: 0.00001" (.02005) → 0.0001" (.0201–.0209) → 0.001" (.021–.029) → 0.010" (.010–.090)

Worked example

  1. Clear the hundred-thousandths. 0.12345 ends in 5 in the 5th place, so take the 0.02005" block. Remainder: 0.12345 − 0.02005 = 0.10340.
  2. Clear the ten-thousandths. Take 0.0204". Remainder: 0.10340 − 0.0204 = 0.08300.
  3. Clear the thousandths. Take 0.023". Remainder: 0.08300 − 0.023 = 0.060.
  4. Finish with a hundredths block. Remainder 0.060" is a single block. Done.
0.02005 + 0.0204 + 0.023 + 0.060 = 0.12345 in — 4 blocks.

FAQ

What is in a 28-piece inch thin gage block set?

A Starrett RC 28 / Mitutoyo Series 516-style thin set typically includes 0.02005", 0.0201–0.0209", 0.021–0.029", and 0.010–0.090". Measuring range is about 0.020–0.240".

When should I use a 28-piece set instead of 36 or 81?

Use the 28-piece thin set for short stacks under about 0.240". For longer inch work switch to the 36-piece or 81-piece set in the calculator.

Can every target be made with a 28-piece set?

No. Targets below the smallest block, above roughly 0.240", or with digit combinations the thin series cannot clear will fail. The calculator reports when no stack exists.
