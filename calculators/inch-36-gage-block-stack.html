Formula

Target = b₁ + b₂ + … + bₙ (minimise n)
36-pc series: 0.0001" (.1001–.1009) → 0.001" (.101–.109) → 0.010" (.110–.190) → 0.100" (.100–.500) → 1–3"

Worked example

  1. Clear the ten-thousandths. 0.7505 ends in 5 in the 4th place, so take a 0.1005" block. Remainder: 0.7505 − 0.1005 = 0.6500.
  2. Clear the hundredths. Take 0.150". Remainder: 0.6500 − 0.150 = 0.500.
  3. Finish with a tenths block. Remainder 0.500" is a single block. Done.
0.1005 + 0.150 + 0.500 = 0.7505 in — 3 blocks.

FAQ

What is in a typical 36-piece inch gage block set?

A common shop set includes 0.050", 0.1001–0.1009", 0.101–0.109", 0.110–0.190", 0.100–0.500", and 1–3" blocks. Some kits add two 0.050" wear blocks.

Why does a 36-piece set need more blocks than an 81-piece set?

The 36-piece set has coarser steps in the thousandths series, so some targets need an extra block or two. The calculator still searches for the shortest stack your set can make.

Can every target be made with a 36-piece set?

Not every length. Gaps appear when the set cannot clear a digit combination. Switch to the 81-piece set in the calculator when a stack is impossible.
