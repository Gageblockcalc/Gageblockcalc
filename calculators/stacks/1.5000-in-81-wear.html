How this was chosen

The digit-by-digit method starts with the block that clears the right-hand digits, then each following block clears the next place until nothing is left. Every extra block adds a wrung joint, so the fewest-block stack gives the least stack-up error and the least handling.

Wear blocks consume 0.100 in, so the inside length is 1.400 in. The calculator lists 1.000 + 0.400 + 0.050 + 0.050. Wring the wear blocks on the outside. 0.400 in is in the 0.050 in series, and the 1 in block stays in the middle.

  1. 0.050 in. Stack so far 0.050 in, and what is left to build, 1.450 in, now ends at the 2nd decimal place.
  2. 0.050 in. Stack so far 0.100 in, and what is left to build, 1.400 in, now ends at the 1st decimal place.
  3. 0.400 in. Stack so far 0.500 in, and what is left to build, 1.000 in, is a whole number.
  4. 1.000 in. Stack so far 1.500 in, which completes the stack.

For a steel stack of 1.500 in the length changes by about 17.3 microinch (0.44 micrometre) for every 1 °C (1.8 °F) away from the 20 °C (68 °F) reference. Typical steel coefficient 11.5 × 10⁻⁶ per °C.

FAQ

Can I mix inch and metric blocks to make 1.500 in?

No. This recipe uses only the 81-piece inch set. 1.500 in stays in inches. Change the set in the calculator if your blocks are the other unit.

Do I need wear blocks for 1.500 in?

This recipe includes them. Wring one 0.050 in wear block on each end. The calculator link sets wear=1 so the same blocks come up.

How do I wring the 1.500 in stack?

Clean the faces. Wring a wear block, then the measuring blocks thickest first (1.000, then 0.400), then the other wear block on the outside. The table lists the same blocks the calculator shows, largest first.

What if one of these blocks is out of the set?

Open the calculator on this size and uncheck the missing block. It searches again. The combination on this page uses each listed block once and adds to 1.500 in.

Is 4 blocks the shortest stack for 1.500 in?

Yes for the 81-piece inch set with every block available and wear blocks included. 1.000 + 0.400 + 0.050 + 0.050 sums to 1.500 in in the set’s integer units.
