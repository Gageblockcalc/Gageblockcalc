How this was chosen

The digit-by-digit method starts with the block that clears the right-hand digits, then each following block clears the next place until nothing is left. Every extra block adds a wrung joint, so the fewest-block stack gives the least stack-up error and the least handling.

Two blocks: 0.150 in and 0.105 in. The 36-piece hundredths series includes 0.150 in, and the thousandths series includes 0.105 in. There is no 0.255 in block in the set.

  1. 0.105 in. Stack so far 0.105 in, and what is left to build, 0.150 in, now ends at the 2nd decimal place.
  2. 0.150 in. Stack so far 0.255 in, which completes the stack.

For a steel stack of 0.255 in the length changes by about 2.9 microinch (0.07 micrometre) for every 1 °C (1.8 °F) away from the 20 °C (68 °F) reference. Typical steel coefficient 11.5 × 10⁻⁶ per °C.

FAQ

Can I mix inch and metric blocks to make 0.255 in?

No. This recipe uses only the 36-piece inch set. 0.255 in stays in inches. Change the set in the calculator if your blocks are the other unit.

Do I need wear blocks for 0.255 in?

Not for this recipe. The stack is the measuring blocks only (0.150 + 0.105). For a stack that will be wrung often, see the wear-block guide and put a wear block on each end.

How do I wring the 0.255 in stack?

Clean the faces and wring thickest first: 0.150 + 0.105. Slide each face together. Do not push a nicked face straight down onto the stack.

What if one of these blocks is out of the set?

Open the calculator on this size and uncheck the missing block. It searches again. The combination on this page uses each listed block once and adds to 0.255 in.

Is 2 blocks the shortest stack for 0.255 in?

Yes for the 36-piece inch set with every block available. 0.150 + 0.105 sums to 0.255 in in the set’s integer units.
