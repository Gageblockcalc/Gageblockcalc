How this was chosen

The digit-by-digit method starts with the block that clears the right-hand digits, then each following block clears the next place until nothing is left. Every extra block adds a wrung joint, so the fewest-block stack gives the least stack-up error and the least handling.

1.005 mm clears the thousandths. 1.12 mm clears the hundredths; the 0.01 mm series runs from 1.01 mm through 1.49 mm. The remainder is 39 mm, which is 25 + 14, and 14 mm is in the 0.5 mm series. An 88-piece set builds the same target as 30 + 9 + 1.12 + 1.005.

  1. 1.005 mm. Stack so far 1.005 mm, and what is left to build, 40.12 mm, now ends at the 2nd decimal place.
  2. 1.12 mm. Stack so far 2.125 mm, and what is left to build, 39 mm, is a whole number.
  3. 25 mm. Stack so far 27.125 mm, and what is left to build, 14 mm, is a whole number.
  4. 14 mm. Stack so far 41.125 mm, which completes the stack.

For a steel stack of 41.125 mm the length changes by about 0.47 micrometre for every 1 °C (1.8 °F) away from the 20 °C (68 °F) reference. Typical steel coefficient 11.5 × 10⁻⁶ per °C.

FAQ

Can I mix inch and metric blocks to make 41.125 mm?

No. This recipe uses only the 112-piece metric set. 41.125 mm stays in millimetres. Change the set in the calculator if your blocks are the other unit.

Do I need wear blocks for 41.125 mm?

Not for this recipe. The stack is the measuring blocks only (25 + 14 + 1.12 + 1.005). For a stack that will be wrung often, see the wear-block guide and put a wear block on each end.

How do I wring the 41.125 mm stack?

Clean the faces and wring thickest first: 25 + 14 + 1.12 + 1.005. Slide each face together. Do not push a nicked face straight down onto the stack.

What if one of these blocks is out of the set?

Open the calculator on this size and uncheck the missing block. It searches again. The combination on this page uses each listed block once and adds to 41.125 mm.

Is 4 blocks the shortest stack for 41.125 mm?

Yes for the 112-piece metric set with every block available. 25 + 14 + 1.12 + 1.005 sums to 41.125 mm in the set’s integer units.
