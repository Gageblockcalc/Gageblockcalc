How this was chosen

The digit-by-digit method starts with the block that clears the right-hand digits, then each following block clears the next place until nothing is left. Every extra block adds a wrung joint, so the fewest-block stack gives the least stack-up error and the least handling.

FAQ

Can I mix inch and metric blocks to make 75 mm?

No. This recipe uses only the 112-piece metric set. 75 mm stays in millimetres. Change the set in the calculator if your blocks are the other unit.

Do I need wear blocks for 75 mm?

Not for this recipe. The stack is the measuring blocks only (75). For a stack that will be wrung often, see the wear-block guide and put a wear block on each end.

How do I wring the 75 mm stack?

Clean the faces and wring thickest first: 75. Slide each face together. Do not push a nicked face straight down onto the stack.

What if one of these blocks is out of the set?

Open the calculator on this size and uncheck the missing block. It searches again. The combination on this page uses each listed block once and adds to 75 mm.

Is 1 block the shortest stack for 75 mm?

Yes for the 112-piece metric set with every block available. 75 sums to 75 mm in the set’s integer units.
