Gage block combinations for common shop sizes

A stack is the fewest gage blocks that wring to a target length. These pages are the solver’s answer for sizes shops look up, written out so you can read the blocks without running JavaScript. Open the calculator for a size that is not listed. Wringing notes are in how to wring gage blocks.
