How this was chosen

The digit-by-digit method starts with the block that clears the right-hand digits, then each following block clears the next place until nothing is left. Every extra block adds a wrung joint, so the fewest-block stack gives the least stack-up error and the least handling.

Largest block first, the calculator lists 2.000 + 0.145 + 0.1006 + 0.050 + 0.050. Wring one 0.050 in wear block, then 2.000, 0.145, and 0.1006, then the other wear block. The two 0.050 in blocks belong on the outside. They are not a 0.100 in block in the middle.

  1. 0.1006 in. Stack so far 0.1006 in, and what is left to build, 2.245 in, now ends at the 3rd decimal place.
  2. 0.145 in. Stack so far 0.2456 in, and what is left to build, 2.100 in, now ends at the 1st decimal place.
  3. 0.050 in. Stack so far 0.2956 in, and what is left to build, 2.050 in, now ends at the 2nd decimal place.
  4. 0.050 in. Stack so far 0.3456 in, and what is left to build, 2.000 in, is a whole number.
  5. 2.000 in. Stack so far 2.3456 in, which completes the stack.

FAQ

Can I mix inch and metric blocks to make 2.3456 in?

No. This recipe uses only the 81-piece inch set. 2.3456 in stays in inches. Change the set in the calculator if your blocks are the other unit.

Do I need wear blocks for 2.3456 in?

This recipe includes them. Wring one 0.050 in wear block on each end. The calculator link sets wear=1 so the same blocks come up.

How do I wring the 2.3456 in stack?

Clean the faces. Wring a wear block, then the measuring blocks thickest first (2.000, then 0.145, then 0.1006), then the other wear block on the outside. The table lists the same blocks the calculator shows, largest first.

What if one of these blocks is out of the set?

Open the calculator on this size and uncheck the missing block. It searches again. The combination on this page uses each listed block once and adds to 2.3456 in.

Is 5 blocks the shortest stack for 2.3456 in?

Yes for the 81-piece inch set with every block available and wear blocks included. 2.000 + 0.145 + 0.1006 + 0.050 + 0.050 sums to 2.3456 in in the set’s integer units.
