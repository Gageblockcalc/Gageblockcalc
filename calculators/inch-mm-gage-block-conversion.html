Inch and Millimetre Gage Block Conversion

Inch blocks and metric blocks are not two labels for one set. The length converts. The stack does not. The international inch is exactly 25.4 mm, so

mm = in × 25.4 in = mm ÷ 25.4

The calculator will not put an inch block and a metric block in the same stack. Convert, then open a set that uses the unit you converted to.

Worked example: 1.000 in

1 × 25.4 = 25.400 mm exactly. The inch stack is the 1.000 block. The metric stacks are not a 25.4 mm block. The sets do not contain one.

FAQ

How many millimetres are in an inch?

The international inch is exactly 25.4 mm. Multiply inches by 25.4 to get millimetres. Divide millimetres by 25.4 to get inches.

Can I mix inch and metric blocks in one stack?

No. This calculator builds a stack from one set. Convert the target, then open a set in that unit. A 0.500 in target is the 0.500 block. The same length in millimetres is 12.7 mm, which is a different stack on a metric set.

Is 1.000 in the same stack as 25.4 mm?

It is the same length. It is not the same blocks. 1.000 in is the 1 inch block on the 81-piece set. 25.4 mm on a 112-piece set is 24 + 1.4. On an 88-piece set it is 20 + 4 + 1.4.
