Formula

Target = b₁ + b₂ + … + bₙ (minimise n)
Clear digits right-to-left: 0.0001" series → 0.001" series → 0.050" series → 1.000" series

Worked example

  1. Clear the ten-thousandths. 1.2345 ends in 5 in the 4th place, so take a 0.1005" block. Remainder: 1.2345 − 0.1005 = 1.1340.
  2. Clear the thousandths. 1.1340 needs …34 in the thousandths, so take 0.134". Remainder: 1.1340 − 0.134 = 1.000.
  3. Finish with a whole block. Remainder 1.000" is a single block. Done.
0.1005 + 0.134 + 1.000 = 1.2345 in — 3 blocks.

FAQ

How many blocks should an inch stack use?

As few as possible. Each wringing interface adds a tiny film and error, so the calculator searches for the shortest stack your set can make, usually 3 to 5 blocks.

Why start from the last decimal place?

Only the 0.0001 inch series blocks can clear the fourth decimal place, so choosing that block first fixes the hardest digit and leaves a remainder the larger series can finish.

Does it work for 36-piece and 28-piece sets?

Yes. Choose the set in the calculator, or open the dedicated 36-piece or 28-piece calculator pages. Smaller sets may need more blocks or may not reach every target exactly.
