Formula

Target = b₁ + b₂ + … + bₙ (minimise n)
Clear 0.001 mm → 0.01 mm → 0.5 mm → 10 mm steps, last digit first

Worked example

  1. Clear the thousandths. 41.125 ends in 5 in the 3rd place, so take a 1.005 mm block. Remainder: 40.120.
  2. Clear the hundredths. Take 1.12 mm. Remainder: 40.120 − 1.12 = 39.000.
  3. Finish with whole blocks. 39.000 = 19 + 20 mm. Done.
1.005 + 1.12 + 19 + 20 = 41.125 mm — 4 blocks.

FAQ

Which metric set should I use, 112 or 88 pieces?

The 112-piece set has finer steps and usually needs fewer blocks. The 88-piece set covers most work with a smaller kit. The calculator handles both.

Can I enter inches and get a metric stack?

Enter the target in mm when a metric set is selected. 1 inch is exactly 25.4 mm if you need to convert.

Why can't my target be made?

Some targets below the smallest block or with more decimal places than the set resolves cannot be built exactly. The calculator will tell you when no stack exists.
