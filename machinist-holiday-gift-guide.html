Dial and test indicators

Which gage block grade is a gift, and which is a master?

A starter set labeled Grade B uses the older workshop name. ASME B89.1.9 grades are 00, 0, AS-1, and AS-2. An AS-2 set is the usual working set for setups. Grade 00 is a laboratory master. Build the sizes you use in the calculator before you buy the tighter grade.

Does a caliper replace a micrometer?

A 0 to 6 inch caliper is the everyday length tool. Its accuracy is coarser than its resolution. A 0 to 1 inch micrometer is the next step when the tolerance is tighter than a caliper can support. Check either one on gage blocks away from zero.

What is the difference between a dial indicator and a test indicator?

A dial indicator measures along its stem and can cover about an inch. A test indicator has a short lever and is for tram, sweep, and comparison. A 0.030 inch test indicator is a short-travel tool. A 1 inch dial is the long-travel tool.
